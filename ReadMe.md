## About Me

<img align="right" width="340" src="https://user-images.githubusercontent.com/74038190/229223263-cf2e4b07-2615-4f87-9c38-e37600f8381a.gif"/>

I'm a **full-stack developer from Gwadar, Balochistan** — building products that solve real problems in markets that mainstream tech has largely overlooked.

My work spans mobile (Flutter), backend (FastAPI + Supabase), and web (React), with a focus on AI-integrated, production-ready systems. I don't build demos. I ship.

- Products with zero existing competition in their market
- AI pipelines that genuinely improve people's lives
- Technology as a tool for cultural and educational equity
- Multi-agent development workflows at velocity

## Projects

<br/>

<table>
<tr>
<td width="33%" valign="top">

### Karwan
**Hyperlocal Food Delivery**

A full-stack delivery ecosystem for Gwadar and Turbat — a genuinely untapped market with zero app-based competition. Restaurants keep their riders; Karwan handles discovery and ordering at 12% commission.

**Architecture:**
- Flutter customer app
- React restaurant dashboard
- React admin panel
- FastAPI + Supabase backend

**Integrations:** Firebase FCM · Twilio WhatsApp · JazzCash · EasyPaisa · Azure

`Flutter` `FastAPI` `React` `Supabase`

</td>
<td width="33%" valign="top">

### Cherág
**AI Study Partner**

Transforms course materials into interactive learning artifacts — flashcards, quizzes, study videos — via a multi-model AI pipeline. Built for students in contexts where quality tutoring is inaccessible.

**Highlights:**
- Multi-model AI content pipeline
- Real-time collaboration
- Personalized learning paths
- Role-based auth

`React` `TypeScript` `Python` `Gemini` `Supabase`

</td>
<td width="33%" valign="top">

### Pajjar
**Language Preservation**

An offline-first dictionary for endangered languages in Balochistan. Community-driven, zero internet dependency — designed for remote areas with unreliable connectivity.

**Highlights:**
- Fully offline-first architecture
- Community-contributed entries
- 100% local SQLite storage
- Long-term preservation mission

`Flutter` `Dart` `SQLite`

</td>
